# NGB_Bank
NGB Bank is a beginner-friendly Java console application that simulates the core operations of a simple banking system. The system is implemented using Object-Oriented Programming (OOP) principles and follows a modular structure suitable for academic projects, mini-projects, and demonstrations. 

🚀 Features

✔️ Account Management

Create a new bank account

Store customer and account details

View account information

✔️ Transactions

Deposit money

Withdraw money

Display available balance

✔️ Modular Java Structure

The project separates logic using multiple classes:

BankMain – Main entry point of the application

account – Manages customer and account-related data

databaseconnection – Handles database connectivity (if configured)
